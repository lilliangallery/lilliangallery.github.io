# Zhang Mingyan — Artist Website

A responsive, English-first personal portfolio site for a Chinese painter based in Malta. Built with plain HTML, CSS and JavaScript for easy deployment to GitHub Pages.

## Included
- Responsive home page with artwork categories
- Artist biography and creative statement
- Exhibition and collaboration section
- Original-work enquiry contact section
- Mobile navigation, basic accessibility, SEO metadata
- No build tools or paid hosting required

## Before publishing
1. Replace `YOUR-EMAIL@example.com` in `index.html` with the email address you want to publish.
2. Replace the `href="#"` values for Instagram, Facebook and TikTok with your real profile URLs. Remove any platform you do not use.
3. Replace the image placeholders with photographs of your own work. Image filenames referenced by the site:
   - `assets/hero.jpg`
   - `assets/gongbi.jpg`
   - `assets/flower-bird.jpg`
   - `assets/baimiao.jpg`
   - `assets/dunhuang.jpg`
   - `assets/malta.jpg`
   - `assets/artist-studio.jpg`
   - `assets/studio-materials.jpg`
4. Add only confirmed exhibition names and dates.
5. Review all text and image permissions before publishing.

The site uses CSS colour fallbacks, so it will still display if image files are missing. The image areas will show their fallback colours until you add your own images.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `zhang-mingyan-art`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Custom domain
If you own `lillian.gallery` and want to use it, add the domain under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions. Do not add a domain unless you control its DNS. Configure HTTPS after DNS verification.

## Sales workflow
This starter website collects enquiries by email; it does not process payments or manage stock. For now, visitors can ask about an original painting, commissions, gallery consignment, or exhibitions by contacting you. Add each work's title, medium, dimensions, price and availability after you have selected the works to publish.
